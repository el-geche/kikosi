# Kbest Play Casino

A **play money only** casino web app. Virtual chips have no cash value: there are no payments, no purchases and no cash-out.

## Features
- Pick a player name and get 1000 starting chips
- Slots (3 reels, pays on pairs and three of a kind)
- Jackpot pool: put chips into a shared pool, and a winner is drawn at random, weighted by chips
- Roulette (bets on red, black, even or odd)
- Leaderboard of the top players by chip balance
- Daily bonus: +250 chips, once every 24 hours
- Chips are saved in the browser's localStorage

## Run locally
```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start   # production build
```
